# sql-bomb identity

sql-bomb shares the [Fusor palette][fusor-brand] and Hypercmd's lowercase
Lexend SemiBold wordmark style.

[fusor-brand]: https://github.com/fusor-rs/fusor/blob/main/apps/landing/BRANDING.md

The symbol combines a round bomb and its fuse with the curved layers of a SQL
database. The upper body, fuse, and spark are vermilion; the lower layers are
oxide. Transparent gaps separate the layers.

| Use | Artwork |
| --- | --- |
| Symbol and small icons | [sql-bomb.svg](sql-bomb.svg) |
| Horizontal logo on light backgrounds | [Light logo](sql-bomb-horizontal.svg) |
| Horizontal logo on dark backgrounds | [Dark logo](sql-bomb-horizontal-dark.svg) |

The SVGs contain vector paths with no embedded images, scripts, or font downloads.
The wordmark uses outlined [Lexend](https://github.com/google/fonts/tree/main/ofl/lexend)
at weight 600. The README selects its logo variant using the reader's color scheme.

The empty results pane uses a 14-column terminal export of the symbol, split into
[upper](sql-bomb-terminal-upper.txt) and [lower](sql-bomb-terminal-lower.txt)
layers for the color reveal. Its wordmark uses the terminal's own font.

| Role | Color |
| --- | --- |
| Upper body, fuse, and spark | Vermilion `#DF5036` |
| Lower layers and interface accent | Oxide `#A83228` |
| Light background and dark-background wordmark | Warm white `#FAF9F6` |
| Dark background and light-background wordmark | Charcoal `#272A2C` |

Use the symbol alone for small icons. Preserve the artwork's proportions and
transparent padding. Keep the layer gaps clear; do not add outlines, shadows,
gradients, or a rust texture. Rust is expressed through the palette.
